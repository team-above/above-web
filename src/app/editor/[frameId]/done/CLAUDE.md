# /editor/[frameId]/done (다운로드 집계 전용 — 무화면)

스펙: docs/specs/04-export.md (변경 2026-07-28 — 기획 확정으로 결과 화면 제거)

- **이 라우트의 페이지뷰 = 다운로드 집계 = 전환율(1차 지표)의 분자다** (PRD §2).
  라우트 경로를 바꾸거나 삭제하면 지표가 끊긴다 — 화면이 없어도 라우트는 유지할 것
- `DoneBeacon`이 렌더 없이 즉시 에디터로 `router.replace` — 사용자는 화면 전환을 느끼지 못하고,
  완료 피드백은 에디터의 "저장했어요" 토스트(스토어 기반, 리마운트 생존)가 담당
- 직접 URL 접근도 같은 동작(에디터로 복귀). 페이지뷰 오염은 무시 가능한 수준으로 수용
