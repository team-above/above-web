# PRD — above (MVP)

- 작성일: 2026-07-26 · 갱신: 2026-07-28 · 상태: **확정** (미결 없음 — M3 검증 단계 진입, Vercel 배포 완료)
- 참고 시안: https://frame-collage--heesunyou.replit.app/above/ (바이브코딩 프로토타입)

## 1. 문제와 기회

인스타그램에 올릴 사진을 "꾸며서" 올리고 싶은 수요는 크지만, 기존 도구(포토샵, 범용 편집 앱)는
과하게 복잡하다. 템플릿을 고르고 → 사진을 넣고 → 다운받는 3단계로 끝나는 초경량 도구로
이 수요를 검증한다.

## 2. 검증 가설

> **H1. 인스타 감성 프레임을 씌워주는 도구가 있으면, 방문자가 실제로 결과물을 다운받아 쓴다.**

- 1차 지표: **방문 → 다운로드 전환율. 목표 25%** (확정 2026-07-27 — 로그인 등 마찰 요소가 없는 초경량 도구임을 감안해 상향. 초기 데이터 보고 조정)
- 보조 지표: 방문자 수, 템플릿별 편집 사용·다운로드 분포, Post/Story 비율 선택 분포
- 측정 도구: **Vercel Analytics** (확정 2026-07-27)
  - 커스텀 이벤트는 Pro 전용이므로 무료(Hobby) 범위에서 **라우트 기반으로 측정**한다:
    템플릿별 편집 사용 = `/editor/[frameId]` 페이지뷰, 다운로드 = 내보내기 완료 화면
    라우트(예: `/editor/[frameId]/done`) 페이지뷰로 집계. 정밀 측정이 필요해지면 Pro 또는 GA4 병행 검토

## 3. 타깃 사용자

**인스타그램 헤비유저 10–20대.** 피드/스토리를 꾸며서 올리는 데 익숙하고,
폴라로이드·낙서·주간 덤프 같은 감성 템플릿 문법을 이미 소비하고 있는 층.
주 접점은 모바일 브라우저 (인스타 인앱 브라우저 포함 — 다운로드 동작 확인 필요).

## 4. MVP 범위

**포함**

- 템플릿 리스트 (홈): 카드형 미리보기, 지원 비율 표기
- 에디터: 슬롯 탭 → 사진 첨부, 슬롯 안에서 드래그·핀치줌으로 위치 조정, Post 4:5 / Story 9:16 전환
- PNG 다운로드 (Post 1080×1350, Story 1080×1920)
- 모바일 웹 최적화 (데스크톱은 중앙 고정 컬럼)

**제외 (검증 후 판단)**

- 계정/로그인, 서버 저장, 공유 링크, 결제
- 커스텀 프레임 제작, 텍스트 입력, 필터/보정

## 5. 템플릿 라인업

**확정 (2026-08-07): 7종 × Post/Story 2비율** — 원본 시안은 `docs/design/frames/<프레임명>/`에
프레임별 폴더로 보관 (v2 레이어 규약: layerNN + sample + sample_gray, 상세는 [스펙 01](specs/01-template-schema.md)).

| id             | 이름           | 구조 요약                                                                 |
| -------------- | -------------- | ------------------------------------------------------------------------- |
| duo            | Duo            | 남색 텍스처 배경 + 세로 슬롯 2개 (사진 2장)                               |
| punching       | Punching       | 상하 반반 2칸, 하늘색 별 오버레이 (위 칸은 별 구멍으로 사진이 비침)       |
| accent         | Accent         | 빨간 배경 밴드 + 상단 소형·하단 대형 슬롯 2개                             |
| weeklydump     | Weekly Dump    | 요일 라벨 7슬롯 그리드(라운드 코너), 라벨·그라디언트가 사진 위에 얹힘     |
| doodle         | Doodle         | 중앙 슬롯 1개, 초록 낙서 스트로크가 사진 경계를 넘어 위에 얹힘            |
| fourleafclover | Fourleafclover | 상하 반반 2칸, 네온 클로버 오버레이 (위 칸은 클로버 구멍으로 사진이 비침) |
| mintdot        | Mintdot        | 캔버스 전체 슬롯 1개 + 민트 도트 패턴이 사진 위에 얹힘                    |

시안은 층 분리 레이어(사진 아래/슬롯 선언/사진 위)로 전달되고, 파생 스크립트가 base/overlay 에셋과
좌표 JSON을 생성한다. 템플릿은 JSON 스키마 + 에셋으로 정의한다 (AGENTS.md 원칙).
Caption(구 frame06)은 라인업 제외(2026-08-07). Mintdot은 같은 날 라인업 편입 확정.
