# PRD — above (MVP)

- 작성일: 2026-07-26 · 상태: **Draft** (템플릿 라인업 확정 대기)
- 참고 시안: https://frame-collage--heesunyou.replit.app/above/ (바이브코딩 프로토타입)

## 1. 문제와 기회

인스타그램에 올릴 사진을 "꾸며서" 올리고 싶은 수요는 크지만, 기존 도구(포토샵, 범용 편집 앱)는
과하게 복잡하다. 템플릿을 고르고 → 사진을 넣고 → 다운받는 3단계로 끝나는 초경량 도구로
이 수요를 검증한다.

## 2. 검증 가설

> **H1. 인스타 감성 프레임을 씌워주는 도구가 있으면, 방문자가 실제로 결과물을 다운받아 쓴다.**

- 1차 지표: **방문 → 다운로드 전환율** (제안 목표: 10%, 초기 데이터 보고 조정)
- 보조 지표: 방문자 수, 템플릿별 다운로드 분포(어떤 프레임이 먹히는지), Post/Story 비율 선택 분포
- 측정 도구: 미정 (Vercel Analytics 후보) — 서비스 연결은 사용자가 진행

## 3. 타깃 사용자

**인스타그램 헤비유저 10–20대.** 피드/스토리를 꾸며서 올리는 데 익숙하고,
폴라로이드·낙서·주간 덤프 같은 감성 템플릿 문법을 이미 소비하고 있는 층.
주 접점은 모바일 브라우저 (인스타 인앱 브라우저 포함 — 다운로드 동작 확인 필요).

## 4. MVP 범위

**포함**

- 템플릿 리스트 (홈): 카드형 미리보기, 지원 비율 표기
- 에디터: 슬롯 탭 → 사진 첨부, 슬롯 안에서 드래그·핀치줌으로 위치 조정, Post 4:5 / Story 9:16 전환
- PNG 다운로드 (Post 1080×1350, Story 1080×1920)
- 모바일 웹 최적화 (데스크톱은 중앙 고정 컬럼)

**제외 (검증 후 판단)**

- 계정/로그인, 서버 저장, 공유 링크, 결제
- 커스텀 프레임 제작, 텍스트 입력, 필터/보정

## 5. 템플릿 라인업

**사용자가 디자인 시안을 직접 첨부할 예정 — 확정 대기.**
참고 시안의 6종(Duo, Punching, Accent, Weekly Dump, Doodle, Caption) 구조를 참고하되,
최종 라인업·에셋은 첨부본 기준으로 한다. 템플릿은 JSON 스키마 + 에셋으로 정의한다 (AGENTS.md 원칙).

## 6. 기능 스펙

기능별 상세 스펙은 `docs/specs/`에 작성한다. 예정 목록:

| 스펙                                    | 상태   |
| --------------------------------------- | ------ |
| 01 템플릿 스키마 (JSON 구조, 에셋 규약) | 미작성 |
| 02 템플릿 리스트 (홈)                   | 미작성 |
| 03 에디터 (슬롯·비율·조작)              | 미작성 |
| 04 내보내기 (PNG 다운로드)              | 미작성 |

## 7. 마일스톤

1. **M1 — 코어**: 템플릿 스키마 확정 + 에디터 코어(슬롯/조작/내보내기) — 템플릿 1종으로 관통
2. **M2 — 라인업**: 사용자 첨부 시안을 스키마로 이식, 전 템플릿 적용
3. **M3 — 검증**: Vercel 배포 + 지표 수집 시작
