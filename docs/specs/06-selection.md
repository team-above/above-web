# 06. 선택 기반 편집 (탭 선택 · 오버레이 컨트롤)

- 상태: **Implemented** (2026-07-28)
- 관련: [스펙 03](03-editor.md)·[스펙 05](05-rotation.md)의 조작 모델을 대체. 배경: 실기기에서
  핀치(줌)와 트위스트(회전)가 충돌해 회전이 어렵다는 피드백 (2026-07-28)

## 인터랙션 모델

- **사진 있는 슬롯 탭 = 선택 토글.** 선택 시:
  - 슬롯 rect에 **여백 없이 딱 붙는 흰 테두리** (참고 이미지 스타일, 안쪽 여백 없음)
  - **고스트(35%) 상시 표시** — 조작 중이 아니어도 잘리는 영역이 보인다
  - 오버레이 버튼: **✕(우상단) = 선택 해제**, **📷(하단 중앙) = 사진 교체**(파일 선택),
    **회전 컨트롤(상단 중앙)** — 형태는 확인 필요(아래 질문)
- **조작은 선택 상태에서만**: 1지 드래그 = 이동, 핀치/휠 = 줌 (트위스트 회전 제거 — 회전은 전용
  컨트롤), Shift+휠 = 회전(데스크톱 보조)
- **빈 슬롯 탭 = 기존대로 바로 파일 선택** (선택 개념 없음)
- **선택 해제**: 사진 재탭, ✕ 버튼, 슬롯 밖(캔버스 배경) 탭, 비율 전환·홈 이동 시 자동 해제
- 사진 교체는 "선택 → 📷"로 이동 (기존 "재탭=즉시 교체"는 폐지 — 탭이 선택으로 대체)

## 상태 모델 변경 — 줌도 사진 속성으로

"각도는 유지되는데 확대는 유지되지 않는다" 피드백 반영:

- **슬롯 공유(사진 속성)**: `rotation`(기존) + **`zoom`(cover 대비 상대 배율, 신규)**
- **비율별 독립**: 오프셋 `{x, y}`만
- 실제 배율 = `minScale(θ, rect) × zoom` — 비율 전환 시 각도·확대감이 그대로 유지되고,
  슬롯 크기 차이는 minScale이 흡수한다
- 사진 교체 시 rotation·zoom·오프셋 전부 초기화 (기존 규칙 유지)

## 렌더 구조

- 선택 테두리·오버레이 버튼은 **셋째 레이어(listening)** — 내보내기(레이어 0만 래스터화)와
  시각 회귀(레이어 0 비교)에서 구조적으로 제외
- 버튼 스타일: 참고 이미지처럼 원형 배지 (✕ = 잉크 배경·흰 아이콘, 📷 = 흰 배경·잉크 아이콘)

## 수용 기준

1. 사진 탭 → 테두리·고스트·버튼 표시, 재탭/바깥 탭/✕ → 해제 (E2E)
2. 선택 상태에서만 드래그·줌이 동작하고, 미선택 사진은 탭해도 위치가 변하지 않는다
3. 📷로 교체 시 새 사진이 cover·무회전으로 들어간다
4. 회전 컨트롤로 임의 각도 회전 (90° 스냅 유지), 빈틈 없음 불변식 유지
5. **비율 전환 시 각도와 확대감(zoom)이 함께 유지**되고 오프셋만 비율별 독립 (E2E 픽셀 검사)
6. 선택 UI가 내보내기 PNG·시각 회귀에 나타나지 않는다
7. 기존 무선택 플로우(빈 슬롯 첨부, 다운로드, 초기화)는 무회귀

## 사용자 확인 결과 (2026-07-28)

- **회전 컨트롤 = 궤도 핸들** — ⟳ 핸들을 잡고 원을 그리듯 드래그하면 사진이 따라 돈다 (90° 스냅 유지)
